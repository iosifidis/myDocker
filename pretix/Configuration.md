# Οδηγός Ρύθμισης Διοργανωτή, Ομάδων, Δικαιωμάτων & Συσκευών στο Pretix

Αυτό το έγγραφο περιγράφει το μοντέλο ανάθεσης διαχείρισης εκδηλώσεων στο Pretix (π.χ. για τη FOSSCOMM), όπου ο κεντρικός διαχειριστής (Admin) δημιουργεί και αναθέτει εκδηλώσεις, ενώ ο τοπικός διαχειριστής (π.χ. `info@fosscomm.gr`) διαμορφώνει την εμφάνιση, τα εισιτήρια και διαχειρίζεται τις συσκευές σάρωσης (pretixSCAN).

---

## 1. Αρχιτεκτονική Μοντέλου Δικαιωμάτων

Στο Pretix τα δικαιώματα κλιμακώνονται ως εξής:

```text
[Organizer: FOSSCOMM]
       │
       ├── [Team: FOSSCOMM] ── (Μέλος: info@fosscomm.gr)
       │          │
       │          ├── Organizer Permissions: Devices (View & change)
       │          └── Event Permissions (περιορισμένα σε επιλεγμένα Events)
       │
       └── [Event: FOSSCOMM 2027] (Δημιουργία από Admin -> Ανάθεση στην Ομάδα)
```

Με τη διαμόρφωση αυτή:
1. Ο χρήστης **δεν μπορεί** να δημιουργήσει νέες δικές του εκδηλώσεις.
2. Ο χρήστης **δεν έχει πρόσβαση** σε άλλες εκδηλώσεις ή σε γενικές ρυθμίσεις του οργανισμού.
3. Ο χρήστης έχει πλήρη αυτονομία στο ανατεθειμένο event (κείμενα, εισιτήρια, ερωτήσεις, συμμετέχοντες).
4. Ο χρήστης μπορεί να προσθέτει συσκευές Android/iOS (pretixSCAN) για την είσοδο.

---

## 2. Αναλυτική Διαμόρφωση Ομάδας (Team Settings)

Η ομάδα διαμορφώνεται από τη διαδρομή: **Διοργανωτές (Organizers) → FOSSCOMM → Ομάδες (Teams) → FOSSCOMM**.

### Α. Γενικές Πληροφορίες
* **Όνομα ομάδας:** `FOSSCOMM`
* **Require all members... to use 2FA:** Προαιρετικό (συνιστάται αν απαιτείται επιπλέον ασφάλεια).

### Β. Άδειες Οργανωτή (Organizer Permissions)
Ελέγχουν τι μπορεί να κάνει η ομάδα σε επίπεδο φορέα (όχι εντός του event):

| Πεδίο | Τιμή | Αιτιολόγηση |
| :--- | :--- | :--- |
| **All organizer permissions** | **Ανενεργό (Κενό)** | Αποτροπή γενικών δικαιωμάτων διαχειριστή. |
| **Εκδηλώσεις** | **`Access existing events`** | Επιτρέπει πρόσβαση μόνο σε υπάρχοντα events. **Μην** επιλέξετε *Access existing and create new events*. |
| **Ρυθμίσεις (Settings)** | **`No access`** | Δεν επιτρέπεται τροποποίηση παραμέτρων του φορέα. |
| **Ομάδες (Teams)** | **`No access`** | Δεν επιτρέπεται τροποποίηση ομάδων ή δικαιωμάτων άλλων χρηστών. |
| **Gift cards / Customers / Reusable media** | **`No access`** | Δεν απαιτούνται για εκδηλώσεις μηδενικού κόστους. |
| **Συσκευές (Devices)** | **`View and change`** | **Κρίσιμο:** Επιτρέπει στον χρήστη να συνδέει κινητά στο pretixSCAN. |
| **Seating plans / Outgoing emails** | **`No access`** | Δεν επιτρέπεται πρόσβαση στα κεντρικά πλάνα θέσεων και outgoing mail settings. |

### Γ. Πεδίο Εφαρμογής Εκδηλώσεων (Scope)
* **Όλα τα γεγονότα (All events):** **Ανενεργό (Κενό)**.
* **Περιορίστε τα συμβάντα (Limit to events):** Επιλέγετε **μόνο** τη συγκεκριμένη εκδήλωση (π.χ. `FOSSCOMM 2027`).

### Δ. Άδειες Εκδηλώσεων (Event Permissions)
Ελέγχουν τι μπορεί να αλλάξει ο χρήστης μέσα στην εκδήλωση που του ανατέθηκε:

| Πεδίο | Τιμή | Σκοπός |
| :--- | :--- | :--- |
| **All event permissions** | **Ανενεργό (Κενό)** | Εξειδικευμένος έλεγχος δικαιωμάτων. |
| **Γενικές ρυθμίσεις** | **`View and change`** | Επεξεργασία περιγραφών, κειμένων, λογοτύπων, ημερομηνιών. |
| **Ρυθμίσεις πληρωμής** | **`View`** ή **`No access`** | Τα εισιτήρια είναι δωρεάν (τιμή 0 €), άρα δεν απαιτείται gateway. |
| **Tax / Invoicing settings** | **`View`** ή **`No access`** | Δεν εκδίδονται φορολογικά παραστατικά για μηδενικές συναλλαγές. |
| **Event series dates** | **`View and change`** | Διαχείριση ημερών συνεδρίου (εφόσον είναι series). |
| **Products, quotas and questions** | **`View and change`** | Δημιουργία/επεξεργασία εισιτηρίων, ποσοστώσεων (quotas), ερωτήσεων (T-shirt, γεύματα). |
| **Παραγγελίες (Orders)** | **`View all and change`** | Προβολή λίστας εγγεγραμμένων, διαχείριση ακυρώσεων, χειροκίνητες εγγραφές. |
| **Κουπόνια (Vouchers)** | **`View and change`** | Δημιουργία εκπτωτικών/προνομιακών κωδικών για ομιλητές/οργανωτές. |
| **Full event/date cancellation** | **`Not allowed`** | Αποτροπή οριστικής διαγραφής ή ακύρωσης του event από τον χρήστη. |

## 3. Ροή Εργασίας: Δημιουργία Νέας Εκδήλωσης (Ετήσια Διαδικασία)

Όταν έρθει η ώρα για μια νέα διοργάνωση (π.χ. FOSSCOMM 2027):

```text
[1. Admin]                 [2. Admin]                 [3. User: fosscomm]
Δημιουργία Event     ───>  Ανάθεση Event στην     ───>  Διαμόρφωση σελίδας,
(π.χ. FOSSCOMM 2027)        Ομάδα FOSSCOMM             Εισιτηρίων & Συσκευών
```

### Βήμα 1: Ο Admin δημιουργεί το Event
1. Σύνδεση ως Superuser.
2. Μετάβαση: **Εκδηλώσεις (Events) → Δημιουργία νέας εκδήλωσης**.
3. Επιλογή Organizer: `FOSSCOMM`.
4. Συμπλήρωση βασικών στοιχείων:
   * **Όνομα:** `FOSSCOMM 2027`
   * **Slug:** `2027` (τελικό URL: `.../fosscomm/2027/`)
   * **Ημερομηνίες έναρξης/λήξης**.
5. Αποθήκευση.

### Βήμα 2: Ο Admin αναθέτει το Event στην Ομάδα
1. Μετάβαση: **Διοργανωτές → FOSSCOMM → Ομάδες → FOSSCOMM**.
2. Στην ενότητα **Περιορίστε τα συμβάντα (Limit to events)**, τσεκάρετε το νέο κουτάκι: `[x] FOSSCOMM 2027`.
3. Πατήστε **Αποθήκευση**.

## 4. Οδηγίες για τον Χρήστη FOSSCOMM (Check-in & Συσκευές)

Ο χρήστης `info@fosscomm.gr` μπορεί πλέον αυτόνομα να ετοιμάσει τον έλεγχο εισόδου:

### Α. Δημιουργία Check-in List (Μέσα στο Event)
1. Είσοδος στο event `FOSSCOMM 2027`.
2. Μετάβαση: **Ρυθμίσεις (Settings) → Λίστες check-in (Check-in lists)**.
3. Δημιουργία νέας λίστας (π.χ. `Γενική Είσοδος`) και επιλογή των εισιτηρίων που γίνονται δεκτά.

### Β. Σύνδεση Συσκευής pretixSCAN (Κινητά / Tablets)
1. Από το κεντρικό μενού του Διοργανωτή, μετάβαση στο: **Συσκευές (Devices)**.
2. Πατήστε **Δημιουργία νέας συσκευής (Create a new device)**:
   * **Όνομα συσκευής:** π.χ. `Gate 1 - Scanner A`.
   * Επιλέξτε την προκαθορισμένη λίστα Check-in.
3. Πατήστε **Αποθήκευση**.
4. Στην οθόνη θα εμφανιστεί ένα **QR Code σύνδεσης**.
5. Στο κινητό (Android ή iOS):
   * Εγκατάσταση της δωρεάν εφαρμογής **pretixSCAN**.
   * Άνοιγμα της εφαρμογής και επιλογή **Scan initialization QR code**.
   * Σάρωση του κωδικού από την οθόνη.

Η συσκευή συγχρονίζει αυτόματα τις εγγραφές (ακόμα και offline) και είναι έτοιμη για σάρωση εισιτηρίων στην είσοδο.
